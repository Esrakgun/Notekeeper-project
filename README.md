# 📓 NoteKeeper
NoteKeeper, notlarınızı kolayca ekleyip düzenleyebileceğiniz basit ve modern bir not tutma uygulamasıdır. Kullanıcı dostu arayüzü ve şık tasarımı ile notlarınızı düzenli bir şekilde saklamanızı sağlar.

 # 🚀 Özellikler
📝 Not Ekleme ve Düzenleme: Yeni not ekleyebilir ve mevcut notlarınızı düzenleyebilirsiniz.
🗑️ Silme İşlevi: Artık ihtiyaç duymadığınız notları kolayca silebilirsiniz.
🎨 Modern Tasarım: Şık ve renkli bir arayüz.
📱 Responsive Tasarım: Mobil ve masaüstü cihazlarla uyumlu.


# 🛠️ Teknolojiler
Bu proje aşağıdaki teknolojiler kullanılarak geliştirilmiştir:

🌐 HTML5
🎨 CSS3
⚙️ JavaScript
🖼️ Google Fonts & BoxIcons
